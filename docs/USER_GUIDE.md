# 📱 DeeChat 用户使用指南

## 🚀 快速开始

### 下载安装
1. 前往 [GitHub Releases](https://github.com/deepractice/deechat/releases) 下载对应平台的安装包
2. **macOS**: 下载 `.dmg` 文件，拖拽到应用程序文件夹
3. **Windows**: 下载 `.exe` 文件，双击安装
4. **Linux**: 下载 `AppImage` 文件，添加执行权限后运行

### 首次启动
1. **启动应用**: 双击DeeChat图标
2. **初始化完成**: 等待所有核心服务初始化（约5-10秒）
3. **开始使用**: 系统会自动进入主聊天界面

## ⚙️ 基础配置

### 配置AI模型
1. 点击右下角 **⚙️ 设置** 按钮
2. 选择 **模型管理** 标签页
3. 点击 **➕ 添加模型** 配置您的AI服务

**支持的AI服务商**:
- **OpenAI**: GPT-3.5、GPT-4系列
- **Claude**: Claude-3系列
- **Gemini**: Gemini Pro系列
- **其他**: 兼容OpenAI API格式的服务

**配置示例**:
```
模型名称: GPT-4
API密钥: sk-your-api-key-here
基础URL: https://api.openai.com/v1
模型ID: gpt-4-turbo-preview
```

### 获取API密钥
- [OpenAI API Key](https://platform.openai.com/api-keys)
- [Claude API Key](https://console.anthropic.com/)
- [Gemini API Key](https://makersuite.google.com/app/apikey)

## 🎭 AI角色系统

### 什么是AI角色？
DeeChat集成了PromptX专业角色系统，提供5个内置专业角色：

- **👨‍💼 Sean**: deepractice.ai创始人，产品和技术决策专家
- **🔧 Luban**: PromptX工具开发大师
- **🎭 Noface**: 万能学习助手，可转换为任何领域专家
- **👩‍🎨 Nuwa**: AI角色创造专家
- **🤖 Assistant**: 基础AI助手

### 如何使用角色？
1. **选择角色**: 在聊天界面左侧选择想要的AI角色
2. **发送消息**: 输入您的问题或需求
3. **角色激活**: AI会自动激活对应角色（显示角色信息）
4. **专业服务**: AI以该角色的专业能力为您服务

**角色切换建议**:
- **产品决策** → 选择 Sean
- **技术开发** → 选择 Luban  
- **学习新知识** → 选择 Noface
- **创建新角色** → 选择 Nuwa
- **日常对话** → 选择 Assistant

## 💬 聊天功能

### 基本对话
1. **发送消息**: 在底部输入框输入文字，按 `Enter` 发送
2. **流式响应**: AI回复会实时显示，提供打字机效果
3. **历史记录**: 所有对话自动保存，可随时查看

### 高级功能

#### 📎 文件上传
- **拖拽上传**: 直接拖拽文件到聊天区域
- **点击上传**: 点击输入框旁的 📎 按钮选择文件
- **支持格式**: PDF、Word、Excel、图片、文本等

#### 🔧 智能工具调用
AI会根据对话内容自动使用合适的工具：
- **文件处理**: 自动解析上传的文档
- **代码执行**: 运行代码片段
- **数据查询**: 搜索和分析数据
- **专业分析**: 使用领域专业工具

#### 💾 会话管理
- **新会话**: 点击左侧 ➕ 按钮创建新对话
- **会话切换**: 点击左侧会话列表切换对话
- **会话重命名**: 右键点击会话名称进行重命名
- **会话删除**: 右键菜单中选择删除

## 📁 工作区功能

### 文档管理
1. **上传文档**: 通过工作区上传各种格式的文档
2. **文档预览**: 直接在DeeChat中预览文档内容  
3. **智能分析**: AI可以分析和总结文档内容
4. **版本管理**: 自动保存文档的不同版本

### 项目协作
- **多项目支持**: 可以管理多个不同的项目
- **文件组织**: 按项目和类别组织文件
- **快速访问**: 通过侧边栏快速访问常用文档

## 🔧 工具和插件

### MCP工具生态
DeeChat支持MCP (Model Context Protocol) 工具生态：

#### 内置工具
- **PromptX工具包**: 角色管理、记忆存储、资源学习
- **文件操作工具**: 文件读写、目录管理、搜索
- **工作区工具**: 项目管理、文档协作

#### 添加新工具
1. 进入 **设置** → **MCP管理**
2. 点击 **添加服务器** 
3. 配置工具服务器信息
4. 启动服务器开始使用

### 常用工具场景
- **代码开发**: 激活Luban角色 + 代码分析工具
- **文档写作**: 上传参考资料 + AI协助写作
- **数据分析**: 上传数据文件 + 分析工具
- **学习研究**: 激活Noface角色 + 资源学习工具

## ⚡ 快捷操作

### 键盘快捷键
- `Enter`: 发送消息
- `Shift + Enter`: 换行
- `Ctrl/Cmd + N`: 新建会话
- `Ctrl/Cmd + ,`: 打开设置
- `Ctrl/Cmd + D`: 切换深色模式

### 鼠标操作
- **拖拽文件**: 直接上传到聊天
- **右键菜单**: 会话管理选项
- **滚轮滚动**: 浏览历史消息
- **双击文本**: 快速选择复制

## 🔒 隐私和安全

### 数据保护
- ✅ **本地存储**: 所有聊天记录保存在您的设备上
- ✅ **加密保护**: API密钥采用加密存储
- ✅ **无数据上传**: DeeChat不会上传您的个人数据
- ✅ **文件安全**: 上传的文件仅在本地处理

### 最佳实践
1. **定期备份**: 导出重要的聊天记录
2. **API密钥安全**: 不要与他人分享您的API密钥
3. **敏感信息**: 避免在聊天中包含过于敏感的信息
4. **软件更新**: 及时更新到最新版本

## 🛠️ 故障排除

### 常见问题

#### Q: AI没有响应或响应很慢
**解决方案**:
1. 检查网络连接
2. 验证API密钥是否正确
3. 检查API服务是否正常
4. 尝试重启应用

#### Q: 角色激活失败
**解决方案**:
1. 等待几秒钟，系统可能正在加载
2. 尝试发送简单消息触发激活
3. 重新选择角色
4. 检查PromptX服务状态

#### Q: 文件上传失败  
**解决方案**:
1. 检查文件大小（建议<50MB）
2. 确认文件格式被支持
3. 检查磁盘空间是否充足
4. 尝试重新上传

#### Q: 应用启动慢或卡顿
**解决方案**:
1. 关闭其他高内存占用应用
2. 重启DeeChat应用
3. 清理临时文件
4. 检查系统资源使用情况
