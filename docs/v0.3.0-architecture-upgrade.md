### 3. 角色状态管理系统 🎭

**解决"角色选择 ≠ 角色激活"的根本性问题**，实现了真正智能的角色管理。

#### 核心创新
- **`useRoleStateManager` Hook**: 声明式角色管理
  ```typescript
  const { roleStateInfo, resetRoleState } = useRoleStateManager({
    enableAutoSync: true,        // 自动同步
    enableNewSessionReset: true, // 新会话重置
    enableConsistencyCheck: true // 一致性检查
  })
  ```

- **智能激活判断**: 基于聊天历史的状态检测
  ```typescript
  private shouldRequestRoleActivation(
    sessionId: string, 
    roleId: string, 
    chatHistory: any[]
  ): boolean {
    // 检查会话中是否已激活该角色
    const isActivated = chatHistory.some(message => 
      message.toolExecutions?.some(tool => 
        tool.toolName === 'promptx_action' && 
        tool.params?.role === roleId
      )
    );
    return !isActivated;
  }
  ```
